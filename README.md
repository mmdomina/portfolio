# Mauro Dómina — Professional Portfolio

Ready for GitHub Pages.

1. Create a public repository named `portfolio` in GitHub account `mmdomina`.
2. Upload `index.html` and `Mauro_Domina_Italian_Sports_Localization_Sample.pdf` to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment choose Deploy from a branch.
5. Select `main` and `/(root)`, then Save.

Expected URL: https://mmdomina.github.io/portfolio/
